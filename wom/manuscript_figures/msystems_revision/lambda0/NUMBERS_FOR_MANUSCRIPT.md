# Numbers for the manuscript: adopted model = Ordinal-BPR with λ_ord = 0

Adopted model: the Ordinal-BPR code path with `lambda_ord` = 0, called **BPR** in the revised manuscript. Other settings are unchanged
(`hard_neg_ratio` 0.5, 32 dims, 1000 epochs, batch 256, lr 0.01). The model was retrained with seed 0 by
`scripts/train_all_models.py --models ordinal_bpr --seed 0`. Settings are recorded in `trained_models/ordinal_bpr_*/training_config.json`.
The submitted λ=0.1 models are archived in `trained_models/archive_submitted_lambda0.1/`.

All outputs are under `wom/manuscript_figures/msystems_revision/lambda0/` and are produced by
`scripts/revision_lambda0_pipeline.sh`. The pipeline is resumable; per-step logs are in `logs/` and runtimes in `pipeline_runtime.tsv`.
The tables below are generated by `scripts/revision_lambda0_numbers.py` (`numbers_tables.md`).

**Columns:**
- **Quoted** is the value printed in the mSystems manuscript.
- **Old (λ=0.1)** is recomputed from the submitted model, or from the submitted results, with the same code as the new value, so old and new differ only by the model.
- **The old column reproduces the quoted numbers.** Fig. 2 from the archived model matches the submitted Fig. 2 outputs byte-for-byte. The fixed Fig. 3 code at λ=0.1 reproduces the submitted rows exactly. The SI scores and ranks match: 51/52 scores to the printed precision (pyruvate is 0.01 off; see below) and 17/17 ranks.

## Figures whose qualitative message changed

1. **Supplementary Fig. 5 / Prompt 3, *Acinetobacter*.**
   - **Old:** malate was the top-ranked BPR prediction (13.06; rank 1 of 311 metabolites for isolate GW460-4).
   - **New:** malate scores 8.16 and drops to **rank 10**. **Succinate is now rank 1** (10.91), and it was not tested in the growth experiment.
   - Among the six tabulated substrates, ectoine (−3.98) is now the lowest, not spermidine (−1.46).
   - The growth result stands, but the caption phrase "Malic acid (the top-ranked BPR prediction, score = 13.06)" and the BPR scores quoted for glucose, ectoine and spermidine describe the submitted model only.
2. **Fig. 3.**
   - **Old:** "improvements significant at the genus and family levels (paired Wilcoxon p < 0.001)".
   - **New:** BPR is significantly better than the naive baseline at **all four levels** (p < 0.001 each). The isolate-level advantage is still negligible in size (median Δ +0.001; 0.905 vs 0.899). The order-level advantage nearly triples (Δ +0.017 → +0.044; 0.776 vs 0.707; p 0.073 → 3 × 10⁻²⁵).
   - The abstract medians become 0.91 → 0.78 (from 0.90 → 0.76).
3. **Fig. 1b.**
   - The figure is now the strict hold-out, so the abstract's "ROC-AUC = 0.94, uniquely robust to embedding dimensionality" is replaced.
   - The figure shows the four submitted models (BPR, WR-MF, SVD, LMF). BPR is the most accurate at every dimension (by only 0.002 over WR-MF at dim 4).
   - BPR is the most stable (0.832–0.875 across dims 4–128; 0.865 ± 0.004 at dim 32).
   - WR-MF and SVD come within 0.003 of it only at dim 4.
4. **Supplementary Fig. 4 and the Prompt 1/2 tables.**
   - **Prompt 1 (*Pseudomonas*):** every quoted score changes, and the rank order of substrates shifts (glycine rank 9 → 16, adenosine 3 → 9, leucine 5 → 3).
   - **Correlation with depletion time:** essentially unchanged and still not significant (ρ −0.44 → −0.43, p ≈ 0.08).
   - **Prompt 2 top-3 substrates:** the set changes for 4 of 8 genera (*Blautia*, *Collinsella*, *Eggerthella*, *Faecalibacterium*), the order changes for 2 (*Bacteroides*, *Eubacterium*), and 2 are unchanged.
   - **Accuracy panels (S4a, S4c, S4d) not recomputed:** they score these predictions against exometabolomics data whose plotting code and data are not in this repo, so they could not be recomputed and may change.

## Corrections found along the way (independent of λ)

- **A third validation isolate is in the training data.**
  - Training organism **MT049** (`wom_8.tsv`) is very likely held-out isolate **MT49** (*Serratia*). The profiles correlate at r = 0.79 on 60 shared compounds and 85% of values are identical; MT49 against the other 23 isolates in that file gives a maximum r of 0.56.
  - The earlier leakage check missed it because of the leading zero.
  - The clean hold-out now removes GW456-R20, FW507-4G11 and MT049; IDs are matched ignoring case, punctuation and leading zeros. The committed λ=0.1 outputs in `msystems_revision/` removed only the first two.
  - MT049 trained **without taxonomy**, so it never contributed to the order-level reference used to score MT49.
  - Please confirm against strain records.
- **Training organisms without taxonomy.**
  - MT049 and FW104-10B1 lack taxonomy because of ID format mismatches with `phylogeny.tsv` ("MT49", "FW104-10B01" → *Rhodanobacter*).
  - GW823-FHT05D11 and MLSD5-FHT05C12 have no phylogeny entry.
  - "SynCom" (`wom_11.csv`) is a synthetic community trained as an organism.
  - These five rows were not changed; fixing them would change the training data.
- **Fig. 3 bug (now fixed).** With the current pandas, missing taxonomy loads as NaN. `molecular_system_biology_fig3.py` then grouped the five no-taxonomy organisms into a pseudo-genus "nan", which gave n = 380/219 instead of 375/213. The script now treats NaN as missing, restoring the submitted design.
- **Pre-existing text inaccuracies (old model too).**
  - *Methylobacterium* (0.166) is not the most consistent genus in Fig. 2b. *Lysinibacillus* is (0.090 old and new).
  - In the Supplementary Fig. 3 scatter, the lowest-GCS reference taxon is Enterobacterales (*Serratia*'s order-level reference; 0.27 vs *Caulobacter* 0.28). So "*Caulobacter* … lowest GCS" was already not strictly true. *Caulobacter* still has the highest embedding diversity and the lowest AUC.
  - Quoted pyruvate (9.44) is 9.43496 on the submitted model, probably double-rounded via 9.435.
